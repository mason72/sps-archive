# App audit — 2026-07-01

Three-agent audit (security / correctness / UX-perf) + hands-on verification.
Criticals were fixed same-day (see Phase 15 in todo.md). This file is the
backlog of verified-but-unfixed findings, ranked.

## Fixed same-day (for the record)
- **Guest favorites never saved** — favorites POST upserted `ON CONFLICT
  (share_id, image_id)` but the unique key was `(share_id, image_id,
  client_email)` → 42P10 → 500 on EVERY favorite since launch. Optimistic UI +
  localStorage masked it completely. Migration 025 re-keyed to
  `(share_id, image_id)`. Reproduced live before fix, verified rows persist after.
- **Shares IDOR** — POST/GET `/api/shares` and PUT/DELETE `/api/shares/[shareId]`
  used the service client (RLS bypass) with no ownership filter: any logged-in
  user could create/list/modify/revoke shares on any event (a created share =
  public access to a private gallery). Ownership gates added.
- **event_date off-by-one** — DATE parsed as UTC midnight, displayed in local
  TZ → US viewers saw the previous day. `timeZone: "UTC"` at 4 display sites.
- **Timing-unsafe comparisons** — X-SPS-Key and password-hash checks used
  `===`; now constant-time.

## Security backlog (do before wide launch)
1. ~~No rate limiting on password/PIN verification~~ **FIXED 2026-07-01**
   (migration 026: auth_attempts + record_auth_attempt(), 5 fails/15min per
   scope:slug:ip, reset on success, wired into verify / verify-pin / download).
2. ~~Share passwords are salted SHA-256~~ **FIXED 2026-07-01** — PBKDF2-SHA256
   (310k iterations, Web Crypto); legacy hashes verify until next password set.
3. ~~Download PIN in query string~~ **FIXED 2026-07-02** — verify-pin returns
   an HMAC-signed share-scoped token (4h TTL); bulk URLs carry ?dt=<token>,
   never the PIN. Raw ?pin= still honored for in-flight old tabs.
4. ~~Email send endpoint galleryUrl + no rate limit~~ **FIXED 2026-07-02** —
   only the slug is kept from the client URL, verified against the user's own
   shares, canonical URL rebuilt server-side (400 on mismatch); 30 sends/hour
   per user via email_sends count.

## Correctness backlog
5. ~~Lightbox navigates the full image set~~ **FIXED 2026-07-01** — navigates
   the visible tab/filter/sort view, stacks flattened person-adjacent, public
   + preview.
6. ~~Section tab counts ignore the favorites filter~~ **FIXED 2026-07-02** —
   counts follow the filter, zero-favorite tabs drop out, active tab hops to
   the first non-empty one (tabs stay put when there are no favorites at all).
7. ~~Favorites/network failures are silent~~ **FIXED 2026-07-01** — failed
   writes toast + revert the heart; server-side failures also alarm via
   reportSystemError → system_errors + admin email (once/context/hour).
8. ~~ZIP download stream silently truncates~~ **FIXED 2026-07-02** — per-image
   fetch retries (3× w/ backoff); anything still un-fetchable is listed in a
   `_MISSING_FILES.txt` inside the ZIP + alarms via reportSystemError, so a
   partial download is never silent; a mid-stream throw finalizes (valid ZIP of
   what succeeded) instead of aborting to a corrupt stream. Client also guards
   double-clicks + clearer "may take a moment" toast. (Selection-share image_ids
   ARE current at request time — the query reads share.image_ids live; no bug.)
9. ~~`.single()` on empty sets~~ **FIXED 2026-07-02** — max sort_order lookup
   uses .maybeSingle(); other sites audited (sections create already did).

## Performance backlog
10. ~~/api/events N+1~~ **FIXED 2026-07-02** — enrichEvents() (lib/events/
    enrich.ts) batches to 3 queries total regardless of event count: cover
    images by id (.in), earliest-image-per-event (first_image_per_event
    DISTINCT ON RPC + idx_images_event_created, migration 029), active shares
    (.in). Verified against live DB: cover keys + share slugs byte-identical to
    the old per-event logic across all 9 of the test account's events
    (scripts/verify-events-enrich.ts).
11. **Gallery payload presigning** — up to 4 presigns × N images per request;
    per-lambda memo misses across instances. Consider deterministic signing
    windows everywhere (getCachedThumbnailUrl already quantizes) or public-lane
    thumbnails for non-sensitive grids.
12. **Public gallery bundle** pulls editor-adjacent deps; audit imports and
    code-split.
